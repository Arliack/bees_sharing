== Introduction

=== Contexte et objectif

La plateforme *Partage d'essaims* permet à des particuliers de signaler la présence d'un essaim d'abeilles sauvage sur leur propriété afin qu'un apiculteur puisse venir le récupérer.
L'application résout un double problème :

* Les essaims abandonnés sans récupération meurent ou créent une nuisance.
* Les apiculteurs cherchent des essaims locaux pour agrandir leur rucher sans coût.

=== Contraintes de conception

* Pas de serveur applicatif : hébergement statique (GitHub Pages).
* Pas d'authentification utilisateur — accès par tokens UUID.
* Zéro dépendance de build (no npm, no bundler, no framework).
* Stockage gratuit (Supabase Free Tier).
* Fonctionnel sur mobile (bottom-sheet, géolocalisation GPS).

== Base de données

=== Table `essaims`

[source,sql]
----
CREATE TABLE essaims (
  id          bigint        GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  token       uuid          DEFAULT gen_random_uuid() UNIQUE NOT NULL,
  prenom      text          NOT NULL,
  email       text          NOT NULL,
  telephone   text,
  commune     text          NOT NULL,
  departement text          NOT NULL,
  latitude    float8        NOT NULL,
  longitude   float8        NOT NULL,
  description text,
  date_dispo  date          NOT NULL DEFAULT CURRENT_DATE,
  disponible  boolean       NOT NULL DEFAULT true,
  statut      text          NOT NULL DEFAULT 'disponible'
                            CHECK (statut IN ('disponible', 'parti', 'recupere')),
  created_at  timestamptz   NOT NULL DEFAULT now()
);
----

[cols="1,1,3", options="header"]
|===
| Colonne | Type | Description

| `id` | bigint | Clé primaire auto-incrémentée
| `token` | uuid | Token de gestion. Généré automatiquement. Transmis par email au déposant.
| `prenom` | text | Prénom public du déposant (affiché sur la carte)
| `email` | text | Email du déposant. Non exposé dans l'API publique. Utilisé pour le lien `mailto:`.
| `telephone` | text | Téléphone facultatif
| `commune` | text | Nom de la commune (issu de geo.api.gouv.fr)
| `departement` | text | Nom complet du département (ex: "Gironde")
| `latitude` / `longitude` | float8 | Coordonnées GPS du marqueur carte
| `description` | text | Description libre (facultative)
| `date_dispo` | date | Date de disponibilité (auto = aujourd'hui)
| `disponible` | boolean | Masque l'essaim de la carte quand `false`
| `statut` | text | État : `disponible`, `parti`, `recupere`
| `created_at` | timestamptz | Date de création, sert au calcul d'ancienneté et à l'expiration à J+7
|===

=== Table `abonnements`

[source,sql]
----
CREATE TABLE abonnements (
  id          bigint        GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  token       uuid          DEFAULT gen_random_uuid() UNIQUE NOT NULL,
  email       text          NOT NULL,
  departement text          NOT NULL,
  created_at  timestamptz   NOT NULL DEFAULT now(),
  UNIQUE (email, departement)
);
----

[cols="1,1,3", options="header"]
|===
| Colonne | Type | Description

| `id` | bigint | Clé primaire
| `token` | uuid | Token de désabonnement, inclus dans chaque email d'alerte
| `email` | text | Email de l'abonné
| `departement` | text | Département surveillé (nom complet)
| Contrainte | UNIQUE | Un email ne peut s'abonner qu'une fois par département
|===

=== Fonctions RPC

==== `gerer_essaim(p_token uuid, p_statut text)`

Clôture un essaim en toute sécurité depuis le frontend (popup carte ou page gerer.html).

[source,sql]
----
CREATE OR REPLACE FUNCTION public.gerer_essaim(
  p_token  uuid,
  p_statut text
)
RETURNS text
LANGUAGE plpgsql
SECURITY DEFINER
AS $$
DECLARE
  _id bigint;
BEGIN
  -- Vérifie que le statut est valide
  IF p_statut NOT IN ('parti', 'recupere') THEN
    RETURN 'statut_invalide';
  END IF;

  -- Recherche l'essaim encore disponible
  SELECT id INTO _id
  FROM essaims
  WHERE token = p_token AND disponible = true;

  IF NOT FOUND THEN
    RETURN 'not_found';
  END IF;

  UPDATE essaims
  SET disponible = false,
      statut     = p_statut
  WHERE id = _id;

  RETURN 'ok';
END;
$$;

GRANT EXECUTE ON FUNCTION public.gerer_essaim(uuid, text) TO anon;
----

[cols="1,3", options="header"]
|===
| Retour | Signification

| `ok` | Essaim mis à jour avec succès
| `not_found` | Token inconnu ou essaim déjà clôturé
| `statut_invalide` | Valeur `p_statut` non reconnue
|===

==== `desabonner(p_token uuid)`

Supprime un abonnement email à partir de son token.

[source,sql]
----
CREATE OR REPLACE FUNCTION public.desabonner(p_token uuid)
RETURNS void
LANGUAGE plpgsql
SECURITY DEFINER
AS $$
BEGIN
  DELETE FROM abonnements WHERE token = p_token;
END;
$$;

GRANT EXECUTE ON FUNCTION public.desabonner(uuid) TO anon;
----

=== Politiques Row Level Security

[source,sql]
----
ALTER TABLE essaims ENABLE ROW LEVEL SECURITY;

-- Lecture publique : seulement les essaims disponibles
CREATE POLICY "lecture_publique" ON essaims
  FOR SELECT USING (disponible = true);

-- Insertion publique sans authentification
CREATE POLICY "insertion_publique" ON essaims
  FOR INSERT WITH CHECK (true);

-- Mise à jour uniquement via RPC (SECURITY DEFINER contourne RLS)
----

`initialiserCarte()`::
Crée la carte Leaflet avec tuiles CartoDB Voyager, contrôle zoom en bas à droite.

* Badge rouge « NOUVEAU » pour les essaims < 24h.

`construireContenuEssaim(essaim, ageHeures)`::
Génère le HTML du popup/bottom-sheet. Contenu partagé entre desktop et mobile.
Protège contre XSS via `escapeHtml()` sur toutes les données utilisateur.

Crée le marqueur Leaflet et le lie à son popup.

Affiche/masque le panneau glissant en bas d'écran. Anime avec `transform: translateY`.

== Fonctionnalités détaillées

=== Carte interactive

* *Tuiles CartoDB Voyager* — plus lisibles que les tuiles OSM par défaut.
* *Marqueurs personnalisés* — forme teardrop CSS, rotation -45°. Couleur verte (frais) ou ambrée (ancien). Badge « NOUVEAU » pour < 24h.
* *Animation pulse* — cercle verdoyant qui s'étend et s'estompe sur les nouveaux essaims (CSS @keyframes `pulse-marker`).
* *Popup desktop* — Leaflet natif, largeur max 300px, coins arrondis.
* *Bottom-sheet mobile* — panneau glissant depuis le bas (pattern Google Maps), activé quand `window.innerWidth < 768`. Overlay sombre, handle cliquable.
* *Contrôle zoom* — repositionné en bas à droite pour ne pas gêner les boutons.

=== Filtrage

* *Par département* — `<select>` avec les 101 départements français (codes + noms). Zoom automatique via Nominatim (debounce 600 ms).
* *Par ville* — Saisie libre avec autocomplete `geo.api.gouv.fr`. Zoom niveau 13 sur la ville sélectionnée.
* *Compteur* — Affiche le nombre d'essaims visibles / disponibles, mis à jour à chaque filtre et à chaque clôture.

=== Bandeau de statistiques saison

Affiché en vert sous le header sur `index.html`. Alimenté par deux requêtes Supabase parallèles (count) :

[source,javascript]
----
const debut = new Date(new Date().getFullYear(), 0, 1).toISOString();
// Compte total depuis le 1er janvier + sous-total récupérés
----

Éléments mis à jour : `#stat-saison`, `#stat-recuperes`, `#stat-disponibles`.

=== Formulaire multi-étapes

Trois étapes avec indicateur visuel (dots + traits colorés) :

. *Vos coordonnées* — Prénom, email, téléphone
. *Localisation* — Commune avec autocomplete, département auto-rempli, mini-carte Leaflet cliquable + bouton GPS
. *Détails* — Description libre, bouton de soumission

Navigation : boutons « Continuer » (validation) et « Retour » (sans perte de données).

=== Alertes email

. L'utilisateur saisit email + département dans le panneau `#panneau-abonnement`.
. INSERT dans `abonnements` (avec gestion du doublon UNIQUE).
. Lors d'un nouvel essaim, le webhook Supabase déclenche l'Edge Function.
. La fonction cherche les abonnés du même département (matching `ilike`).
. Resend envoie un email HTML avec :
** Nom de la commune et département
** Lien direct vers la carte
** Lien de désabonnement tokenisé

=== Gestion de l'état d'un essaim

Trois voies pour clôturer un essaim :

. *Popup/bottom-sheet carte* — boutons inline dans le popup, visibles de tous (pas d'auth, confiance utilisateur).
. *Page gerer.html* — lien reçu à la création, token UUID dans l'URL.
. *Expiration automatique* — les essaims > 7 jours sont filtrés côté client (pas supprimés en base, conservation des stats).

=== Confidentialité de l'email

L'email du déposant n'est **jamais chargé en masse** avec les données de la carte.

* La vue `essaims_publics` exclut les colonnes `email` et `telephone`.
* Le rôle `anon` n'a aucun droit `SELECT` direct sur la table `essaims` (REVOKE explicite).
* L'email n'est récupéré qu'à la demande, via la RPC `obtenir_contact_essaim(p_id bigint)`, uniquement quand l'utilisateur clique sur « Je suis intéressé(e) ».
* Il transite une seule fois, pour un seul essaim, et sert immédiatement à construire le `mailto:` en JS. Il n'est jamais inséré dans le DOM.

Ce mécanisme empêche le moissonnage en masse des emails par un simple appel API.

=== Évolutions possibles

==== Priorité haute

* *Photo de l'essaim* — Upload vers Supabase Storage avec compression Canvas côté client (~200 KB). Auto-suppression à la clôture.

== Glossaire

[cols="1,3", options="header"]
|===
| Terme | Définition

| *Essaim*
| Colonie d'abeilles qui a quitté sa ruche et cherche un nouvel habitat. Phase migratoire de 24-72h, récupérable par un apiculteur.

| *Token UUID*
| Identifiant aléatoire 128 bits. Sert de clé de gestion sans nécessiter d'authentification.

| *RPC*
| Remote Procedure Call. Fonction PostgreSQL exposée comme endpoint REST par Supabase.

| *RLS*
| Row Level Security. Mécanisme PostgreSQL limitant les lignes accessibles selon le rôle/contexte.

| *SECURITY DEFINER*
| Attribut d'une fonction SQL qui s'exécute avec les droits de son créateur, contournant RLS.

| *Edge Function*
| Fonction serverless Deno déployée sur le réseau Supabase, proche des utilisateurs.

| *Bottom-sheet*
| Panneau UI qui glisse depuis le bas de l'écran sur mobile (pattern Google Maps).

| *BaaS*
| Backend-as-a-Service. Supabase fournit DB, auth et API sans serveur à gérer.

| *Resend*
| Service d'envoi d'emails transactionnels avec API REST simple.
|===
